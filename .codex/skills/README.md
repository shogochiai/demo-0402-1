# Skills

This directory contains project-specific skills generated by `etherclaw init`.
They are intentionally local to this repo, so an agent can recover the operating
model without needing the original `etherclaw` monorepo as context.

## Generated Skills

- `project-layout/SKILL.md` — repository layout, important files, package roles
- `governed-workflow/SKILL.md` — governed PR flow, review, release, and auditor steps
- `demo-operations/SKILL.md` — demo startup, tmux layout, Codex supervision (demo mode only)
